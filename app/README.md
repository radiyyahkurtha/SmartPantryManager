# Smart Pantry Manager

## App Description
Smart Pantry Manager is a Java Android application designed to help users manage pantry items and find recipes based on the ingredients they have available.

The app allows users to add, view, edit and delete pantry items. It also provides suggested recipes using a strict ingredient-matching rule.

## Database
The application uses SQLite for local data storage. SQLite was chosen because it is built into Android, works without an internet connection, and is suitable for storing pantry and recipe data locally.

## Setup and Run Instructions
1. Open the Smart Pantry Manager project in Android Studio.
2. Allow Android Studio to sync the Gradle files.
3. Select an Android emulator or connected Android device.
4. Click the Run button in Android Studio.
5. The application will install and launch on the selected device.
